# 碧池拾光

横屏 H5 锦鲤投喂小游戏。原生 HTML、CSS、JavaScript 与 Canvas 2D 实现，无 npm 运行依赖、无构建步骤。

## 运行

在此目录启动静态服务：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 <http://127.0.0.1:8000/>。也可双击根目录 `index.html`；`file://` 下各浏览器的存储行为可能不同，推荐通过 HTTP 运行。

`index.html` 自动进入 `code/index.html`。部署静态站点时需包含根入口、完整 `code/` 和根目录 `assets/`；不要将原始参考资料、测试或其他工作区文件作为公开发布内容。

## 已实现

- 十二关完整配置：目标分数、时间、投喂次数与文档表格一致。
- 主菜单、3×4 选关、暂停、帮助、通关／失败、重试与终章结算。
- 动态锦鲤平滑转向追食、食粒消耗、有限投喂、连击、得分浮字和水波粒子。
- 本机存档、关卡解锁、各关最佳成绩、旅程分数、昵称、音效设置与最多 20 条本机榜单。
- `Esc`／空格暂停和继续，方向键移动投喂点、`F` 投喂；弹窗焦点约束。
- 响应式布局、移动触控、可关闭的竖屏提示、后台自动暂停和 Web Audio 合成音效（默认关闭）。
- TapTap 内部适配层：离线、失败、超时、异常数据与成功状态处理；可配置的原生平台排行榜入口和成绩上报代码。

## 玩法

点击游动的锦鲤附近投喂。每团鱼食包含多个食粒，锦鲤吃到食粒即得分。连续吞食间隔不超过 2.4 秒时积累连击。达到目标立即通关；时间耗尽则失败。打开选关、帮助或排行榜也会暂停关卡，关闭后回到原状态。

单次得分：`12 + min(连击数, 5) × 2 + floor(关卡编号 / 2)`。

**旅程分数的首版约定**：累计各关最佳分数，重玩仅将超过旧纪录的部分计入总分，避免反复刷第一关使榜单失去意义。解锁进度始终只增不减。刷新或重进会重新开始存档关卡，不保存关内剩余时间。

## 测试

安装 Node.js 后运行：

```bash
node --test tests/game.test.cjs
```

测试覆盖规则、存档恢复、排行榜排序、暂停和失败状态、适配层异常，以及 12 关 × 10 个随机种子的可达成性模拟。它不替代真实设备和 TapTap 容器测试。详情见 `doc/验证记录.md`。

## TapTap 接入状态

普通浏览器默认离线，只显示本机成绩。已经读取当前环境提供的 TapTap MCP 排行榜和云存档指南；原设计文档中“当前环境没有 MCP 工具”的描述属于编写时状态，现已过时。

原生排行榜接入代码已按照真实指南提供的 `tap.getLeaderboardManager()`、`submitScores()`、`openLeaderboard()` 编写，需要实际应用的排行榜 ID 和 TapTap 运行环境才能联调。目前没有创建或发布平台应用、排行榜，也没有进行真实账号成绩提交或云同步。云存档保留可注入提供器契约，尚未实现平台原生云档案管理。具体边界见 `doc/TapTap接入说明.md`。

## 素材与已知限制

当前背景为 `assets/backgrounds/pond-jade-v1.png`，使用内置 `image_gen` 按用户提示词生成：正交顶视浅玉色池塘，中央开阔，无动物、文字或 UI。原始提示词和一次定稿修订保存在 `assets/prompts/pond-jade-v1.md`。目标尺寸 2560×1440，工具实际输出为 1672×941，已在资源记录中注明；未标为原生 2560×1440。此前的截图裁切底图保留在 `code/assets/pond-scene.jpg`，页面已不再使用。游戏锦鲤全部由 Canvas 动态绘制。

当前是可玩的首版原型：关卡具备可达成性，但难度、帧率、真实音频输出、跨设备行为与 TapTap 容器适配仍需实机验证。存档只属于当前浏览器与来源；存储受限时会提示，不能保证刷新保留。
